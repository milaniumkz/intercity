# Удаление аккаунта — App Store Review 5.1.1(v)

Путь в обеих ролях: **Профиль → Удалить аккаунт → пароль → Удалить навсегда → Аккаунт удалён → Понятно → Вход**.

Это необратимое удаление, а не деактивация. Сервер удаляет исходную запись User и DriverProfile, refresh-токены, сохранённые карточные токены, привязки карт, документы водителя, чаты и персональные сведения. Доступ по старому access-токену прекращается, потому что его User больше не существует. Номер освобождается для новой регистрации. В админке удалённый аккаунт не отображается.

История сумм поездок и платежей остаётся с обезличенным служебным владельцем, не имеющим телефона, пароля, профиля и возможности входа. Адреса и координаты собственных поездок удаляются. Файлы удаляются сразу после транзакции; при ошибке файловой системы очередь автоматически повторяет очистку. Запрос удаления требует пароль действующего аккаунта и использует только ID из JWT, без передаваемого клиентом userId.

Назначенную/начатую поездку нужно завершить перед удалением; необработанную оплату — дождаться. Обращение в поддержку не требуется. Перед удалением пользователь может вывести доступные деньги; бонусы не выводятся. Поисковые заказы отменяются автоматически. Удаление аккаунта не является операцией возврата или вывода денег.

## Запись для Apple на физическом iPhone

После установки новой iOS-сборки используйте отдельный тестовый аккаунт с нулевым балансом и без активных поездок. Не удаляйте реальный аккаунт для демонстрации.

1. Включите запись экрана на физическом iPhone, покажите регистрацию или вход тестового аккаунта.
2. Откройте «Профиль», покажите «Удалить аккаунт».
3. Откройте подтверждение. Введите пароль тестового аккаунта.
4. Нажмите «Удалить навсегда», дождитесь «Аккаунт удалён».
5. Нажмите «Понятно», покажите экран входа.
6. Убедитесь, что вход прежним аккаунтом невозможен. При повторной регистрации этим номером создаётся новый аккаунт.
7. Добавьте ссылку на запись в App Store Connect → App Review Information → Notes и в ответ на сообщение ревью. Не публикуйте пароль/номер реального пользователя в записи.

Браузерная запись и скриншоты не заменяют требуемую Apple запись с физического устройства. Текущий документ не подтверждает наличие опубликованной iOS-сборки, записи или отправленного ответа Apple.

## Черновик ответа Apple после установки и проверки новой сборки

Account deletion is now available directly in the app for both passenger and driver accounts: Profile → Delete account. The user confirms with their account password and taps Delete permanently. The original account and personal profile are removed, all sessions are revoked, and the app displays a deletion confirmation before returning to the sign-in screen. This is permanent deletion, not temporary deactivation, and no phone call or email to customer support is required. ## Операционные ограничения

Удаление применяется к рабочей базе и активному каталогу uploads. Сроки хранения резервных копий и внешнего платёжного провайдера регулируются отдельной политикой. При восстановлении старой резервной копии оператор обязан повторно применить удаления, совершённые после даты копии; нельзя возвращать удалённые аккаунты в доступную пользователям базу. Этот PR не заявляет, что исторические резервные копии или данные внешнего провайдера уже очищены.
