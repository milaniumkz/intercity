# ВТБ: тестовая интеграция для российских профилей

Основная сумма в приложении — RUB. Банку передаётся KZT (ISO 398).
Фиксированный внутренний курс: **1 RUB = 7 KZT**.
Пример: 100.00 RUB → 700.00 KZT; банковский запрос amount=70000.
Сумма банковской операции и курс сохраняются в записи и при проверке не пересчитываются.

## Маршрутизация
- Страна определяется сервером по городу профиля (RU).
- Российский водитель: «Пополнить» → сумма в рублях → подтверждение суммы в тенге → ВТБ.
- Российский пассажир: «Карта» в форме поездки → тестовый checkout ВТБ.
- Казахстан: существующие Kaspi/Kassa24; ВТБ не создаёт платежи для профиля KZ.
- Отдельные записи VtbSandboxPayment не пополняют настоящий кошелёк и не переводят реальную поездку в состояние «оплачена».
- Для настоящего заказа тестовая оплата не считается оплатой. Тестовый выбор карты блокирует создание настоящего оплаченного заказа.

## API (префикс /api)
- GET /wallet/vtb/sandbox — доступность и последняя тестовая операция пополнения.
- POST /wallet/vtb/sandbox/payments — amount в RUB, currency=RUB, purpose=TOPUP или TRIP_TEST, необязательный requestKey.
- POST /wallet/vtb/sandbox/payments/:id/check — проверка собственной операции.
- GET/POST /payments/vtb/sandbox/callback — уведомление банка; его статус не считается доказательством оплаты, сервер запрашивает банк повторно.
- GET /payments/vtb/sandbox/return — возврат в кошелёк или форму поездки без изменения финансового статуса.

Подтверждается только bank orderStatus=2 с actionCode=0, совпадением orderNumber, currency=398 и сохранённой суммы KZT.
Повторные запросы используют одну запись; callbacks не создают финансовых проводок.

## Секреты и развёртывание
API-логин и пароль отсутствуют в клиенте и открытых файлах.
infra/vps/vtb-sandbox.sealed.json содержит RSA-OAEP-SHA256 ciphertext.
Ключ расшифровки хранится только на VPS: shared/vtb-sandbox-secrets/private.pem (0600).
Деплой проверяет исходники и сохраняет backup, расшифровывает настройки атомарно в серверный .env и сохраняет ключ в защищённом backup.
VTB_SANDBOX_ENABLED по умолчанию false. Рабочий банковский endpoint в этом коде отсутствует.
