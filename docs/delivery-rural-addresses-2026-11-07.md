# Доставка, грузовые и сельские адреса — 7 ноября 2026

## Причины и изменения

- OSM хранит улицу «Шәкәрім», а ввод «Шакарима» не совпадал с токенами локального индекса. Поиск сохраняет исходное написание и проверяет вариант без падежного окончания. Номер дома остаётся обязательным фильтром: другой дом не подставляется.
- При создании доставки ближайшее село могло заменить выбранный город (например, Zhilandy вместо Усть-Каменогорска). Подтверждённое название/алиас из справочника принимается, если координаты находятся в пределах 50 км. Для неизвестного или удалённого названия используется существующий обратный поиск. В карточке водителя показывается опубликованный адрес пассажира.
- Выбор города грузового заказа очищал весь заказ. Теперь очищаются адреса, а дата, груз, вес и комментарий сохраняются.
- Доставка не пропускает шаг параметров без будущей даты/времени. Дату можно изменить и на шаге подтверждения.
- Кнопка предложения цены для доставки расположена вверху карточки, до адресов. Пассажир подтверждает предложенную цену; бесплатное автоматическое назначение не добавлялось.
- Поиск населённых пунктов принимает «село», «посёлок», «деревня», «аул» и сокращения. Черногорка (50.13644, 82.45329) уже присутствует в справочнике.
- На первом экране межгорода рядом с маршрутом добавлено поле «Примечание / комментарий». Оно сохраняется в черновике, передаётся API и отображается в карточке водителя. Можно уточнить село/ориентир при выборе ближайшего населённого пункта.
- Повторная доставка одного веб-уведомления использует стабильный тег и не требует повторного звука. Разные статусы заказов и сообщения сохраняют разные теги.

## Проверки

Локальные тесты используют отдельную PostgreSQL QA-базу с откатом фикстур. Push-запросы подменены: реальные уведомления пользователям и реальные заказы при проверках не отправляются.

Выполнено пять полных прогонов Flutter (последний: 413 успешно, 9 ранее существовавших пропусков), пять целевых прогонов Flutter по 9 сценариев, пять прогонов API/локального индекса/QA PostgreSQL по 34 теста. Общий Node-прогон: 136 успешно, 43 пропуска тестов, требующих отдельного окружения; нужные сценарии базы повторно запущены с QA URL. Анализатор Flutter не обнаружил ошибок, release web собран. Browser fixture разрешений: пять прогонов по 16 групп. Основные сценарии: Шакарима 143 при недоступных внешних геокодерах; точность номера дома; Черногорка с префиксом; сохранение города доставки; публикация/предложение/подтверждение доставки; сохранение комментария после возврата и отказа 409; сохранение грузовых параметров после выбора города; редактируемая дата; доступность кнопки на мобильном экране; стабильность тегов уведомлений.

## Ограничения

Новые платные сервисы, серверы и ключи не добавлены. Полнота сельских адресов зависит от справочника и OSM; ручная точка и комментарий остаются доступными. Изменение отображения существующих заявок не переписывает их адреса в базе. Доменное предупреждение Chrome о подозрении на спам определяется браузером: сайт не может снять его программно. Замена тегов ограничивает дубли, но не гарантирует изменение оценки Chrome. Проверки в Chromium не заменяют испытание системных окон на физическом Android.
