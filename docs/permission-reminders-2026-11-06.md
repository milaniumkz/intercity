# Повторные напоминания о разрешениях веб-версии

Для авторизованного пользователя напоминание о геолокации и уведомлениях возвращается через 30 секунд после закрытия и при возврате в приложение, пока доступ не разрешён. Состояние проверяется раз в 5 секунд без автоматических запросов GPS или системных окон. Системный запрос вызывается только нажатием пользователя; после запрета показываются инструкции настроек браузера. На iPhone для push нужна установленная на главный экран веб-версия с поддержкой Web Push.

Напоминание скрывается при вводе текста, регистрации, восстановлении пароля и видеопроверке. Используется одна компактная панель. Обычная подсказка установки сохраняет прежнюю паузу на сутки. После выдачи геолокации GPS повторяется без перезагрузки; выбранный вручную адрес сохраняется.

Проверки: пять полных прогонов Flutter (404 успешных, 9 существующих пропусков в каждом), Flutter analyze без замечаний, release web build; пять прогонов браузерного набора с восемью группами сценариев: повтор, отказ, выдача доступа, iOS-инструкция установки, ввод в Shadow DOM, защищённые маршруты, возврат на страницу, устаревшие ответы и ошибки мостика. Браузерные сценарии используют тестовые состояния, без отправки реальных уведомлений.

Дополнительно пять раз проверены оба сценария в собранном Flutter Web с реальными разрешениями Chromium и тестовым аккаунтом: выдача GPS без перезагрузки восстанавливает автоматический адрес; ручной адрес сохраняется. Всего 10 сценариев, без ошибок JavaScript и без переходов страницы. Бизнес-API подменён тестовыми ответами, плитки карты настоящие.

Браузер запрещает принудительное повторное открытие системного диалога после отказа. Напоминание внутри сайта не заменяет разрешение пользователя в настройках. Изменения относятся к веб-версии, публикация нового APK не выполняется.
