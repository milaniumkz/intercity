# Заработок водителя

В профиле водителя доступен `/driver/earnings`. API `GET /api/driver/earnings?period=2026-10&currency=KZT` использует исключительно владельца JWT, проверяет наличие водительского профиля и читает согласованный снимок БД (`RepeatableRead`). Ответ не содержит налоговых идентификаторов или реквизитов других пользователей.

- Период — календарный месяц по времени Казахстана (UTC+5), правая граница исключается. KZT и RUB не суммируются.
- Поездки — завершённые городские заказы и межгородские заявки. Для межгорода используется согласованная цена выбранного предложения. Старые записи без `completedAt` учитываются по `updatedAt`; экран явно отмечает такую оценку даты.
- Стоимость поездок показывается отдельно от полученного дохода. Наличные/переводы учитываются по цене завершённой поездки. Карта входит в доход только после фактического зачисления водителю (`SETTLED`, `earningsCredited`), без возврата. Ожидающие и возвращённые оплаты видны отдельно.
- Комиссия — фактические списания из кошелька владельца, связанные с этими завершёнными поездками. Для межгорода учитывается и принятие, и завершение. Дата списания может быть раньше месяца завершения. Пополнение, вывод, покупки топа, промо-бонусы и списания другого владельца не являются комиссией.
- Итог поездок = полученный доход − комиссия − начисленные социальные обязательства по этим поездкам. Налоговые записи выбираются по источнику поездки независимо от месяца их учёта, чтобы отложенное зачисление карты не потеряло начисление. Это не доступный для вывода баланс.
- Налоговая карточка — отдельный итог **месяца налогового учёта**, включая реферальные доходы. Используются существующие `ACCOUNTED`-записи, четыре компонента, фактическое удержание и платёжные документы `TaxRemittance`. `REVIEW` не превращается в рассчитанный налог; незавершённый учёт отмечается как предварительный.
- Для самозанятых показаны ОПВ, ОПВР, СО и ОСМС. Исторические записи СНР видны и после изменения текущего статуса. RUB не получает казахстанские удержания. Для ИП/физлица без истории СНР личные налоги не рассчитываются автоматически и не выдаются за нулевую налоговую обязанность.

Раздел только читает существующий учёт: не начисляет новые комиссии/налоги, не собирает долг и не освобождает ожидающие выплаты. Изменений схемы БД не требуется.
