# Уведомления водителя

В браузере звук активируется нажатием «Выйти на линию». В этот момент запрашивается разрешение на уведомления и сохраняется FCM-токен текущего аккаунта. Если браузер ранее запретил уведомления, разрешите их в настройках сайта и повторно выйдите на линию. На iPhone веб-push требует добавления сайта на домашний экран.

Для серверного push используется Firebase HTTP v1, а не отключённый legacy API. Добавьте JSON сервисного аккаунта проекта inter-city-pkzpps в GitHub Actions secret `FIREBASE_SERVICE_ACCOUNT_JSON` с правом отправки FCM. Не помещайте ключ в исходники или чат. При публикации он передаётся отдельно от архива и сохраняется в защищённой конфигурации сервера; резервная копия конфигурации сохраняется до изменения. Альтернативно backend поддерживает `GOOGLE_APPLICATION_CREDENTIALS` с доступным внутри контейнера файлом.

Для браузерного push настройте GitHub Actions secret `INTERCITY_FIREBASE_WEB_VAPID_KEY` (публичный ключ Web Push из Firebase Cloud Messaging). Без серверного сервисного аккаунта push при закрытом приложении не доставляется; звуковой сигнал и получение заказа при открытом приложении работают отдельно.

Публикация выводит только наличие серверной конфигурации, без её значений. Ошибки Firebase логируются с HTTP-статусом, без токенов и ключей. Время жизни push ограничивается сроком предложения заказа.
