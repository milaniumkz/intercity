# Предпросмотр камеры без блокировки интерфейса

Определение положения лица в веб-версии выполняется в отдельном classic Web Worker. В него передаётся ImageBitmap до 384 пикселей; одновременно обрабатывается только один кадр. Частота подсветки — до 2,5 Гц в предпросмотре и до 1,25 Гц во время записи. Исходный видеопоток и серверная проверка движений остаются без уменьшения частоты.

У CameraPreview сохраняется ключ при переходе от предпросмотра к записи. При временной паузе HTML-видео делается попытка возобновить muted-воспроизведение. Ошибка или отсутствие Worker/OffscreenCanvas отключает локальную подсветку, сохраняя возможность видеозаписи; успешная позиция не имитируется.

Локальная проверка Chromium, замедление CPU ×4, движущийся canvas-поток с общедоступным тестовым портретом, запись 14 секунд: видеовремя 14,005 с, 17 результатов детектора, максимальная задержка 100-мс контрольного таймера 306 мс, WebM 780385 байт. Проверены пустой кадр, одно и два лица. Внешних запросов нет. Это проверка отзывчивости интерфейса, а не успешности биометрической идентификации или гарантии поведения каждого телефона.
