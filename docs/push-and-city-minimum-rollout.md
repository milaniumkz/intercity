# Рассылка и минимальная стоимость городских поездок

- В KZ минимальная стоимость `TariffCity.minPrice` — 500 KZT; в RU — `round(500 / driverRouteTopPolicy.kztPerRub, 2)` RUB. Используется существующий курс из админки, внешних источников курса нет. Значение курса не меняется.
- Миграция обновляет минимумы всех городских тарифов KZ/RU, добавляет эконом для городов без тарифов. Стоимость километра, минуты, начальная стоимость, классы, отключённые тарифы и другие страны сохраняются. Это минимум, не фиксированная цена всей поездки. Грузовые, доставка и межгород не меняются.
- Сохранение курса через настройки админки в одной транзакции обновляет минимум российских городов. Новые города используют тот же курс. Рубли округляются до копеек, тенге — существующим шагом 50.
- Рассылка использует общий PushService Firebase HTTP v1 вместо отключённого legacy FCM API. Обрабатывает получателей страницами, учитывает аудиторию/город, исключает заблокированных, убирает дубликаты токенов.
- Нет токенов — явная ошибка без ложного успешного завершения. Админка показывает принято сервисом / ошибки / причину и обновляет активную задачу каждые 4 секунды. Ответ Firebase означает приём сообщения, не подтверждение показа на устройстве.
- iPhone web: подсказка добавления на главный экран, отдельная кнопка разрешения push в установленной версии, повторное подключение токена и ошибки без ложного успеха. Требуется поддерживаемая iOS и разрешение пользователя. Сборка сохраняет Firebase service worker, удаляя только старый Flutter worker/cache.
- Отображаемое имя Android/PWA — InterCity. Установленный Android требует новой подписанной сборки и публикации; ключ подписи пока отсутствует в GitHub Actions.

Проверки: backend build, backend suite, реальные PostgreSQL-тесты тарифов/миграции с откатом, Flutter analyze/tests обоих приложений; браузерные проверки iPhone-подсказки (обычный браузер, установленная версия, отказ, ошибка регистрации). Реальная фоновая доставка на iPhone требует проверки на устройстве, эмуляция её не подтверждает.
