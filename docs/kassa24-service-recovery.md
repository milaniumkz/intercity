# Kassa24: восстановление после технических работ

Существующие KASSA24_LOGIN и KASSA24_PASSWORD сохраняются. Не заменять их данными другого банка и не переключать реальные операции в demo.

При отклонении создания оплаты API возвращает HTTP 503 / KASSA24_UNAVAILABLE с номером локальной заявки. Баланс не изменяется. Локальная заявка не является подтверждением оплаты. При неизвестном результате нельзя повторять списание или вручную зачислять средства без проверки.

После завершения работ провайдера вручную проверить авторизацию запросом статуса, создание ссылки оплаты, успешную оплату и однократное зачисление, повтор callback, отмену, отказ и разрыв соединения. Проверять совпадение orderId, merchantId, суммы и demo перед зачислением. Не публиковать реквизиты API, номера карт или персональные данные в логах.

Автоматические выводы ещё требуют отдельного исправления: старый /withdraw не соответствует документированному /payment/create с type=1. До реализации и проверки исходящих статусов не считать автоматический вывод работающим. Приём оплаты и вывод средств — отдельные проверки.
