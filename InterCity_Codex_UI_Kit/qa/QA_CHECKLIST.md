# QA Checklist

## Smoke

- Приложение запускается без runtime errors.
- Работает светлая тема.
- Работает тёмная тема.
- Навигация между passenger/driver работает.
- На критических экранах нет console errors.

## Passenger city fixed

- Выбрать `Город → Легковой`.
- Выбрать точку А и точку В с координатами.
- Проверить, что маршрут построен.
- Проверить, что цена появилась внизу.
- Переключить Эконом/Оптимал/Комфорт/Бизнес.
- Убедиться, что цена меняется.
- Выбрать оплату: наличные, карта, бонусы.
- Создать заказ.
- Проверить, что водитель видит цену, класс и оплату.

## Passenger city auction

- Выбрать `Город → Аукцион`.
- Проверить, что цены и класса машины нет.
- Создать заявку.
- Водитель предлагает цену.
- Пассажир видит предложение.
- Пассажир принимает предложение.
- Остальные предложения становятся недоступными.

## Manual address

- В fixed fare ручной адрес без координат должен блокироваться.
- В auction ручной адрес должен разрешаться.
- В intercity ручной адрес должен разрешаться.
- В delivery ручной адрес должен разрешаться.
- Водитель видит бейдж `Адрес введён вручную`.
- UI не показывает голые координаты, если есть readable address.

## Intercity

- Создать межгородскую заявку.
- Выбрать оплату.
- Проверить доп. опции: багаж, животные, детское кресло, комментарий.
- Водитель видит заявку и способ оплаты.
- При принятии межгородской заявки проверить списание комиссии.
- Повторный accept/retry не создаёт второе списание.
- При недостатке средств показан экран пополнения.

## Delivery

- Создать доставку по городу.
- Создать межгородскую доставку.
- Создать доставку по РФ.
- Проверить, что бонусов нет в способах оплаты.
- Проверить, что ручной адрес разрешён.
- Исполнитель видит данные груза и способ оплаты.

## Common states

- Адрес не найден.
- Нет интернета.
- Loading / skeleton.
- Empty states.
- Error states.
- Поддержка.
- Настройки и тема.
