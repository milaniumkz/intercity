# Design System — InterCity Violet Premium

## Brand direction

- Основной цвет: фиолетовый / violet.
- Ощущение: дорого, солидно, современно, спокойно.
- Интерфейс: карты, нижние карточки, крупные CTA, минимум шума.

## Buttons

### Primary

- violet gradient or `accent.primary` fill;
- white text;
- radius 16;
- height 52–56;
- disabled opacity 0.45;
- loading spinner.

### Secondary

- transparent or soft violet fill;
- violet text;
- 1px violet border;
- height 48–52.

## Cards

- rounded 20;
- light: white surface, subtle shadow;
- dark: elevated graphite-violet, subtle border;
- use generous padding 16–20.

## Maps

- Light map: pale, low saturation, purple route.
- Dark map: deep navy/purple, violet route glow.
- Never show raw coordinates as primary address text.
