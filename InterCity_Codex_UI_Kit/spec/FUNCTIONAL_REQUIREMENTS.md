# Functional Requirements — InterCity

## Продуктовые режимы

InterCity поддерживает:

1. Город
   - Легковой / fixed fare;
   - Аукцион.
2. Межгород.
3. Доставка
   - по городу;
   - межгород;
   - по РФ.

## Город: Легковой / fixed fare

**Пассажир:**

- выбирает `Город → Легковой`;
- вводит точку А и точку В;
- выбирает класс авто: `economy | optimal | comfort | business`;
- выбирает способ оплаты: `cash | card_transfer | bonuses`;
- видит системную цену;
- создаёт заявку.

**Валидация:**

- точка А должна иметь координаты;
- точка В должна иметь координаты;
- маршрут должен быть построен;
- цена должна быть рассчитана;
- ручной адрес без координат запрещён.

**Водитель:**

- видит цену;
- видит класс авто;
- видит способ оплаты;
- принимает заявку.

## Город: Аукцион

**Пассажир:**

- выбирает `Город → Аукцион`;
- вводит точку А и точку В;
- ручной адрес разрешён;
- выбирает способ оплаты: `cash | card_transfer | bonuses`;
- не вводит цену;
- не выбирает класс машины;
- ждёт предложения водителей;
- выбирает одно предложение.

**Водитель:**

- видит заявку;
- видит адреса и способ оплаты;
- видит бейдж `Адрес введён вручную`, если координат нет;
- предлагает цену;
- может обновить своё предложение, если бизнес-логика разрешает.

## Межгород

- Нет отдельного аукционного режима.
- Пассажир создаёт заявку.
- Ручной адрес разрешён.
- Оплата: `cash | card_transfer | bonuses`.
- Водители видят способ оплаты и могут предложить/принять условия.
- Если реализована комиссия водителя — списывать только за фактически принятую заявку.

## Доставка

- Режим отдельный от поездок.
- Типы: `delivery_city | delivery_intercity | delivery_rf`.
- Бонусы в доставке не показывать.
- Оплата: `cash | card_transfer`.
- Ручной адрес разрешён.
- Исполнитель видит груз, адреса, оплату, комментарий.

## Адреса

Во всех карточках и деталях показывать человекочитаемый адрес. Координаты не показывать пользователю, если есть нормальная подпись адреса.

Приоритет отображения:

1. manualAddress;
2. addressLabel/formattedAddress/displayName;
3. readable reverse-geocoded address;
4. `Выбранная точка на карте`;
5. координаты только техническим fallback.
