# InterCity — Codex UI Implementation Kit

Этот архив подготовлен для быстрой вёрстки и подключения мобильного интерфейса InterCity в проекте через Codex.

## Что внутри

- `assets/design-boards/` — визуальные борды экранов в фиолетовой премиальной стилистике.
- `prompts/CODEX_IMPLEMENTATION_PROMPT.md` — главный промт для Codex, который нужно вставить целиком.
- `spec/` — текстовая спецификация экранов, навигации, бизнес-логики, API и QA.
- `tokens/` — дизайн-токены в JSON, TypeScript и CSS.
- `react-native-expo-starter/` — стартовые React Native / Expo компоненты и структура, чтобы Codex быстрее сверстал UI, если проект на React Native/Expo.
- `qa/QA_CHECKLIST.md` — сценарии проверки после подключения.

## Как использовать

1. Распакуй архив в корень проекта или прикрепи архив к задаче Codex.
2. Открой `prompts/CODEX_IMPLEMENTATION_PROMPT.md` и вставь его в Codex.
3. Скажи Codex использовать `assets/design-boards` как визуальный референс, а `spec` и `tokens` как источник истины.
4. Codex должен сначала изучить текущий проект, определить стек, роутинг, auth, API, карту, базу и существующие компоненты.
5. После реализации Codex должен запустить проект, проверить основные сценарии и дать отчёт по файлам, тестам и оставшимся вопросам.

## Важно

Картинки — визуальный референс. Если в картинке где-то текст получился неидеальным, использовать формулировки из файлов `spec/*.md`.  
Источник истины по логике: `spec/FUNCTIONAL_REQUIREMENTS.md`, `spec/SCREEN_INVENTORY.md`, `spec/DATA_AND_API_CONTRACT.md`.

## Главная цветовая идея

InterCity должен выглядеть дорого и солидно: фиолетовый / violet как основной брендовый акцент, белая премиальная светлая тема и глубокая графитово-фиолетовая тёмная тема.
