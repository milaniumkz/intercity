# React Native / Expo starter

Эти файлы не являются полным приложением. Это стартовая база компонентов и дизайн-токенов, которую Codex может быстро адаптировать в существующий проект, если он на React Native / Expo.

## Что есть

- `src/theme/tokens.ts` — фиолетовая light/dark тема.
- `src/theme/useICTheme.tsx` — ThemeProvider.
- `src/components/*` — базовые компоненты: экран, кнопка, карточка, текст, input, payment selector, vehicle selector.
- `src/screens/ExampleCityFixedScreen.tsx` — пример сборки fixed fare экрана.
- `src/navigation/routes.ts` — стартовые названия маршрутов.

Codex должен не копировать слепо, а встроить в текущую архитектуру проекта.
